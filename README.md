# CS111 Lab 18: pass by value and pass by reference

1. Clone this repo: `git clone `
2. Go into the folder: `cd fa2026-cs111-lab18-starter`
3. Open `passing.cpp` and follow the steps on the Lab 18 page in Brightspace.
4. Compile: `g++ passing.cpp -o passing`
5. Run: `./passing` (on Windows: `passing.exe`)
6. Submit `passing.cpp` in Gradescope.
